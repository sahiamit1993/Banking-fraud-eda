Tech Stack

Project Pipeline

StageModuleWhat it does
1. Ingestionsrc/ingestion/data_loader.pyExplicit schema CSV load, CSV → Parquet conversion, stratified sampling
2. Cleaningsrc/cleaning/data_cleaner.pyNull removal, deduplication, IQR Winsorization (preserves fraud rows)
3. EDAsrc/eda/exploratory_analysis.py6 analyses: class dist, amounts, time patterns, correlations, box plots, heatmap
4. Feature Engg.src/feature_engineering/feature_builder.pyTime bins, LogAmount, rolling window, VectorAssembler + StandardScaler
5. Spark SQLsrc/sql_analysis/spark_sql_queries.py6 business queries: fraud by hour, amount band, financial impact, percentiles
6. Insightsnotebooks/banking_fraud_eda.ipynbActionable recommendations, optimization demos, caching benchmarks

Setup Instructions

  1. Clone the repository 
    git clone https://github.com/YOUR_USERNAME/pyspark-banking-eda.git
cd pyspark-banking-eda
  2. Install Java 11 (required by Spark) 
    # macOS
brew install openjdk@11

# Ubuntu / Debian
sudo apt-get install openjdk-11-jdk

# Verify
java -version
  3. Create virtual environment & install dependencies 
    python -m venv venv
source venv/bin/activate        # Mac/Linux
venv\Scripts\activate           # Windows

pip install -r requirements.txt
  4. Download dataset from Kaggle

    Go to kaggle.com/datasets/mlg-ulb/creditcardfraud, download and extract, then place creditcard.csv into data/raw/

  5. Launch Jupyter and run the notebook 
    jupyter lab
# Open: notebooks/banking_fraud_eda.ipynb
# Run: Kernel → Restart & Run All

How to Run

Option A — Full Notebook (Recommended)

jupyter lab
# Open notebooks/banking_fraud_eda.ipynb
# Runs all 8 sections automatically
# Plots auto-saved to outputs/plots/

Option B — Run individual modules

from src.utils.spark_session import create_spark_session
from src.ingestion.data_loader import load_csv, save_as_parquet
from src.cleaning.data_cleaner import run_cleaning_pipeline
from src.feature_engineering.feature_builder import run_feature_engineering
from src.sql_analysis.spark_sql_queries import register_temp_view, run_all_sql_analysis

spark = create_spark_session()
df    = load_csv(spark, "data/raw/creditcard.csv")
df    = run_cleaning_pipeline(df)
df    = run_feature_engineering(df)
register_temp_view(df)
run_all_sql_analysis(spark)

Option C — Push to GitHub

git init
git add .
git commit -m "Initial commit: PySpark Banking Fraud EDA"
git remote add origin https://github.com/YOUR_USERNAME/pyspark-banking-eda.git
git push -u origin main

Business Insights

0.172%
Fraud rate — highly imbalanced dataset requiring special ML treatment
$22
Median fraud amount vs $87 for legitimate — fraudsters use small amounts to avoid detection
V17, V14
Top predictive features (r = -0.327, -0.302) — use these first in fraud scoring
10pm–6am
Night-time peak fraud period — enable step-up auth during these hours
#InsightRecommended Action
10.17% fraud rate but ~0.27% of total transaction valuePrioritise high-value fraud case investigation
2Fraud median amount ($22) far below legitimate ($87)Flag micro-transactions from new/unknown merchants
3Night-time fraud spike between 10pm–6amAdd 2FA or biometric check for night transactions
4V14, V17, V12, V10 are the strongest fraud signalsUse these as primary inputs to scoring model
5Most fraud clusters in the $0–$50 amount bandApply stricter rules for small-amount new-merchant txns
